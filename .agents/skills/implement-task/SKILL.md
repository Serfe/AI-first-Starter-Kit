# Implement task

Use this workflow to implement a bounded requirement.

1. Read the requirement and its acceptance criteria.
2. Load only the relevant `.ai/` context and `.agents/rules/`.
3. Inspect the affected code and make a minimal implementation plan.
4. Implement the change while preserving established conventions.
5. Add or update focused tests and documentation.
6. Run relevant verification and summarize the result.

Stop and ask for direction when a material product or architecture decision is missing.
