# Project overview

AI-first Starter Kit demonstrates a small, portable structure for AI-assisted software development. It separates reusable working guidance from project-specific context and avoids tool-specific copies of the same prompt.

## Initial scope

- Two agent roles: developer and reviewer.
- Three workflows: implementation, verification, and review.
- Compatibility adapters for Codex, Claude Code, and OpenCode.

The repository does not include Serfe's internal delivery framework or a production application.
