# ADR-001: Keep shared AI guidance canonical

## Status

Accepted

## Context

Supporting multiple AI coding tools can lead to several inconsistent copies of the same instructions.

## Decision

Keep roles, rules, and workflows in `.agents/`. Keep project-specific documentation in `.ai/`. Use lightweight tool adapters to reference those sources.

## Consequences

Guidance is easier to maintain and review. Tool adapters may still require occasional compatibility testing, and Claude Code skill links need a documented fallback on systems where symbolic links are inconvenient.
